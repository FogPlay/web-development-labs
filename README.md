Каждая лабораторная находится в отдельной папке и запускается независимо.

## Visual Studio Code

Откройте файл `web-development-labs.code-workspace` или папку нужной лабораторной. Терминал для команд npm должен находиться в папке, содержащей `package.json`.

## Git и публикация

Рабочая папка репозитория — эта директория, а не родительская папка чата. Сюда не включены методички и предыдущая презентация по маркетингу.

После проверки работ сохраните изменения с вашим настоящим именем и email:

```sh
git config user.name "Ваше имя"
git config user.email "Ваш email или noreply-адрес GitHub"
git add .
git commit -m "Complete lab 01: React blog"
```

Создайте пустой репозиторий GitHub и подключите **его реальный адрес**:

```sh
git remote add origin https://github.com/YOUR_LOGIN/web-development-labs.git
git push -u origin main
```

`YOUR_LOGIN` — пример, его необходимо заменить. Удалённый репозиторий и авторизация будут подключены отдельно. `package-lock.json` включается в Git, зависимости и результаты сборки — нет. Не добавляйте `.env`, пароли и токены в коммиты.

Страницы можно позже разместить на GitHub Pages отдельным этапом; выгрузка исходников в GitHub и публикация работающего сайта — разные действия.
