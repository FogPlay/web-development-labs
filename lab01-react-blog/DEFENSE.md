# Подготовка к защите лабораторной №1

## Что показать

1. Запустить `npm run dev`, открыть блог и показать шесть карточек.
2. Уменьшить окно: сетка меняется с трёх колонок на две и одну.
3. Показать `App.jsx`: он подключает компоненты и передаёт массив.
4. Показать `articles.js` и добавить временную карточку с новым id: появятся карточка и новый счётчик. Затем отменить изменение.
5. Показать CSS-модуль и правила Flexbox.
6. Запустить `npm run lint` и `npm run build`.

## Как движутся данные

`articles.js` экспортирует массив. `App` импортирует его и передаёт в `ArticleList` через `articles={articles}`. Список вызывает `map()`, для каждого объекта создаёт `ArticleCard` и передаёт `article={article}`. Карточка деструктурирует объект и вставляет значения в JSX. В `Header` отдельно передаётся длина массива как `articleCount`.

## Ответы на вопросы

**Что делает Vite?** Запускает сервер разработки, обрабатывает JSX и CSS-модули, обновляет страницу при изменениях и собирает файлы для публикации. React отвечает за интерфейс. Create React App — другой, более старый способ подготовки проекта; здесь выбран Vite из задания.

**Что такое CSS-модуль?** Файл `*.module.css`. Импорт возвращает объект классов: `import styles from './Header.module.css'`. В JSX используется `className={styles.header}`. Сборщик генерирует имена классов, чтобы одинаковые названия из разных модулей не конфликтовали.

**Зачем семантические теги?** `header` обозначает шапку, `nav` — навигацию, `main` — основное содержимое, `section` — смысловой раздел, `article` — самостоятельную карточку, `footer` — подвал, `time` — дату. На странице один h1, разделы используют h2, карточки — h3. Это помогает ориентироваться в структуре документа.

**Как работает Flexbox?** У списка `display: flex` и `flex-wrap: wrap`: карточки переносятся на новую строку. `gap: 24px` задаёт промежутки. При трёх колонках `flex-basis: calc((100% - 48px) / 3)` делит ширину за вычетом двух промежутков. `flex: 0 0 ...` запрещает растягивать последнюю неполную строку. Медиа-запросы меняют ширину на половину и 100%.

**Что означает flex: 1 1 calc(...), как в методичке?** Первое число разрешает рост, второе — сжатие, третье задаёт исходный размер. В этой реализации использовано `0 0`, чтобы последняя строка сохраняла ширину колонок. Оба варианта используют Flexbox.

**Зачем key?** Это стабильный идентификатор элемента списка для React. Он помогает сопоставлять элементы при вставке, удалении и перестановке. Берём уникальный `article.id`; индекс массива и случайное число здесь не нужны. `key` не передаётся компоненту как обычный prop.

**Что такое props?** Данные, которые родитель передаёт дочернему компоненту. `ArticleCard` получает объект `article`. Дочерний компонент не изменяет переданные данные.

**Зачем StrictMode?** В разработке помогает обнаруживать потенциальные проблемы. Некоторые действия могут вызываться дополнительно для диагностики; в production этих проверок нет.

**Почему картинки локальные?** Чтобы демонстрация не зависела от доступности внешнего сервиса. SVG отображаются обычным тегом `img`, путь берётся из данных карточки.

**Что хранится в Git?** Исходники, конфигурация, документация и lock-файл. `node_modules` заново устанавливается через npm, `dist` заново собирается. Секреты из `.env` не публикуются.
