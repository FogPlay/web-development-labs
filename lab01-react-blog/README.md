# Лабораторная работа №1 — React Blog

Учебный блог на **React + Vite, JavaScript**. Выполнен по презентации «Лабораторная работа 1 (1)», а не по сокращённому описанию в программе курса.

## Запуск в Visual Studio Code

Откройте **эту папку** через «Файл → Открыть папку». В терминале VS Code:

```sh
npm install
npm run dev
```

Перейдите по адресу из терминала, обычно http://localhost:5173. Остановить сервер: Ctrl+C. Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd install` и `npm.cmd run dev`.

Нужен Node.js **22.12+ или 24 LTS** и npm. Используется современный Vite, поэтому указанного в старой методичке Node.js 18 недостаточно. Не нужно устанавливать React или Vite глобально.

## Проверка и сборка

```sh
npm run lint
npm run build
npm run preview
```

`build` создаёт `dist/`, `preview` показывает собранную версию. Исходный `index.html` не предназначен для запуска двойным щелчком: нужен сервер Vite. После первого `npm install` внешние изображения и сервисы не требуются.

## Выполненные требования

- React + Vite, функциональные JSX-компоненты, `StrictMode`.
- Семантика `header`, `nav`, `main`, `section`, `article`, `footer`, `time`.
- Компоненты `Header`, `ArticleList`, `ArticleCard`, отдельный `Nav`.
- Локальные CSS-модули у каждого компонента, базовые глобальные стили отдельно.
- Шесть карточек из `src/data/articles.js`, передача через props, `map()` и стабильный `key={article.id}`.
- **Flexbox**: 3 колонки выше 960 px, 2 колонки при 601–960 px, 1 колонка до 600 px включительно.
- Рабочие якоря, переход к содержанию с клавиатуры, видимый фокус, поддержка уменьшения анимации.
- Локальные SVG-обложки и иконка; интернет для картинок не нужен.
- Дополнительно: `Nav` со своим CSS-модулем и счётчик на основе `articles.length`.

На странице три смысловых секции: вступление, статьи и информация о проекте. Карточки показывают анонсы, полные страницы статей не входят в задание.

## Где что менять

```text
src/
├── main.jsx                # монтирование приложения
├── App.jsx                 # сборка страницы и передача массива
├── App.module.css
├── index.css               # сброс и общие переменные
├── components/
│   ├── Header/             # шапка и число статей
│   ├── Nav/                # навигация
│   ├── ArticleList/        # map() и адаптивная сетка
│   └── ArticleCard/        # одна карточка
└── data/articles.js        # тексты, авторы, даты, изображения
public/images/              # локальные обложки
```

Данные и имена авторов — демонстрационный контент из примера задания, а не реальные публикации. Для добавления карточки добавьте объект с уникальным `id` в массив. Счётчик обновится автоматически. Удаление и изменение массива также не требуют правок JSX.

## Самопроверка

Откройте страницу при ширинах 1280, 768, 390 и 320 px. Проверьте колонки и отсутствие горизонтальной прокрутки. Пройдите навигацию клавишей Tab, проверьте все якоря. Контрольные вопросы разобраны в [DEFENSE.md](DEFENSE.md).

Пункты методички про 7–8 карточек и 4 колонки оставлены как упражнения: основной вариант сохраняет обязательные 6 карточек и сетку 3/2/1.

## Git

Репозиторий находится уровнем выше, в `web-development-labs/`. Команды публикации и правила размещения следующих работ — в корневом README. `node_modules/`, `dist/` и `.env` не отправляются в Git. `package-lock.json` сохраняется в репозитории для воспроизводимой установки через `npm ci`.
