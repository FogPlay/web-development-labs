Требования к стеку
React (Vite или Create React App);
JavaScript (без TypeScript);
OMDb API (требуется бесплатный API‑ключ).
Важно: OMDb API бесплатен, но требует ключа. 
Студентам нужно зарегистрироваться на omdbapi.com, получить ключ и сохранить его в переменной окружения или прямо в коде (для учебной среды допустимо).
Быстрый старт с OMDb
Зайдите на , выберите FREE! (1,000 daily limit), введите email.
Ключ придёт на почту (иногда до часа; Yahoo/Hotmail могут задерживать).
Готово — можно сразу делать запросы.

Подсказки и частые ошибки
Не храните API‑ключ в открытом виде в репозитории. Для лабораторной работы допустимо, но обязательно предупредите студентов.
Всегда проверяйте data.Error от OMDb. Это основной способ понять, что результатов нет.
Используйте encodeURIComponent для запроса, чтобы корректно обрабатывать пробелы и спецсимволы.
Не делайте запросы в цикле без ограничений. Если добавляете автопоиск, обязательно используйте debounce или useEffect с таймером.
Обрабатывайте отсутствие постера. OMDb часто возвращает N/A, это не ошибка, а особенность данных.
